# Curso de Python

Este curso visa introduzir a linguagem de programação Python, do zero ao intermediário - feito por alunos da FEA-USP e do IME-USP.

O modelo é um _self-study course_ dividido em aulas gravadas, materiais de consulta e listas, totalmente gratuito.

## Como executar o material

Cada notebook tem no topo um botão **Abrir no Colab** — clicando nele o material roda no
navegador, sem instalar nada. Os notebooks que leem planilhas (Aulas 5 e 6, Lista 6) pedem o
upload do arquivo `.xlsx` correspondente para a sessão do Colab.

Para rodar localmente, a partir da raiz do repositório:

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook
```

Requer Python 3.9 ou superior.

## Organização

- `Materias das Aulas/` — o material de cada aula.
- `Lista de Exercícios/` — as listas (`Lista_Aula_N.ipynb`) e os gabaritos, em arquivos
  separados (`Gabarito_Aula_N.ipynb`). Tente resolver a lista antes de abrir o gabarito.
